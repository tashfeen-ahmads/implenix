# Quick Start

An Implenix deployment goes live in 72 hours from kickoff, including regulated industries. This page is the compressed version of what happens in each phase.

## Phase 1, Discovery (hours 0 to 24)

We listen to 20 to 40 of your recent inbound call recordings and read your existing intake script if one exists. Output: a call-category map, a caller-vocabulary catalog, and a written "hard-stop" list of things the agent should never say or do.

## Phase 2, Agent build (hours 0 to 24)

We draft the 7-section prompt (system role, tone, intake script, transfer rules, escalation flows, edge cases, hard-stops). You review and approve section by section. This is the phase where operator judgment matters most.

## Phase 3, Integration wiring (hours 24 to 48)

CRM connection with read and write scopes. Calendar integration with real availability read. Twilio SMS provisioning. Warm-transfer bridge configuration. Every integration verified end-to-end with a test write appearing in your source system.

## Phase 4, Test-call battery (hours 48 to 72)

We run 30 to 50 mock calls against a shadow number. Standard bookings, edge cases, adversarial calls, hostile callers, unusual accents. The owner listens to every one. Anything unexpected gets tuned before cutover.

## Phase 5, Sign-off and go-live (by hour 72)

You sign off and we forward your inbound number to the agent. If you also want to port the number, porting runs in parallel and does not delay go-live. We silent-monitor for the first 48 hours minimum, a human is available to catch a bad transfer. After 72 hours of clean operation, the deployment is production.

## What keeps it inside 72 hours

- Recent call recordings and API credentials ready at kickoff.
- One deployment owner on your side who can approve the script quickly.
- For complex integrations (ServiceTitan, multi-location, practice management systems), admin access shared before kickoff.
- For regulated industries (HIPAA healthcare, legal with conflict-check integration, financial services with licensing gates), your compliance sign-off scheduled before kickoff.
